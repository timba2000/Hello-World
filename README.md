# Hello World CRM

A simple, voice-enabled CRM experiment.

## Features

- **Contact Management**: Basic SQLite schema for storing contacts.
- **Voice Integration**: Python workflow (`voice_workflow.py`) for handling voice interactions.
- **Testing**: Shell script (`test_voice.sh`) for quick verification.

## Setup

1.  Install dependencies: `npm install`
2.  Initialize the database: `node crm/scripts/init_db.js`
3.  Run the voice workflow: `python3 voice_workflow.py`
